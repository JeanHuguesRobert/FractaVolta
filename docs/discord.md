FractaVolta is deliberately present in several spaces. No single platform is the project, and no platform account is the canonical identity of FractaVolta.

This page is a public entrance point. Choose the channel that best matches what you want to do.

## Join the conversation

The FractaVolta Discord server is open to anyone who wants to follow, ask, discuss, or contribute.

**[Join the FractaVolta Discord](https://discord.gg/JRrCmz55Nk)**

The invitation is intended to remain public and non-expiring. Discord is a living discussion space, not the durable source of truth for project decisions or documentation.

## Contribute to the project

For code, issues, technical proposals, research notes, and durable implementation traces, use GitHub:

**[FractaVolta on GitHub](https://github.com/JeanHuguesRobert/FractaVolta)**

GitHub is the preferred place for work that should remain inspectable, versioned, and linkable over time.

## Understand FractaVolta

**[fractavolta.com](https://fractavolta.com/)**

## Participation principle

FractaVolta aims for low-friction participation. Presence on a platform does not itself create membership, authority, mandate, or decision power. Contributions can move between Discord, GitHub, the public site, and other spaces while durable project state remains independent of any one provider.

This gateway is intentionally small. Additional participation paths should be added only when real use demonstrates that they are useful.
